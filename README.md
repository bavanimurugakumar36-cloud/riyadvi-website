# Riyadvi Software Technologies — Website Revamp

A premium, futuristic, full-stack corporate website for **Riyadvi Software Technologies**, combining modern React development, immersive 3D experiences, AI-assisted development, dynamic content architecture, lead generation, backend APIs, MongoDB, and an administrative dashboard.

---

## Project Overview

This project is a complete website revamp for Riyadvi Software Technologies.

The goal is to create a modern digital experience that positions Riyadvi as a technology and digital solutions partner while providing users with clear pathways to:

- Explore services
- View portfolio and case studies
- Learn about the company
- Read technology and business articles
- Explore career opportunities
- Submit enquiries
- Request a business health checkup
- Generate a software project plan
- Download a personalized project plan as a PDF
- Submit job applications

The website is built as a **dynamic multi-page application**, rather than a single static landing page.

---
